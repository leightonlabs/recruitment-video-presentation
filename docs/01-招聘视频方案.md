**智数科技2027届校园招聘视频方案｜让AI看懂真实世界**

版本：v2 制作版。时长120秒，20个分镜，25 fps；16:9主版，9:16版由代码按竖版版式原生重排。用户确认的业务方向为AI应用开发，本片根据招聘材料中的岗位设置，把它展开为“数据加工—质量验证—算法研究—服务AI应用”。

本文件供评审阅读。逐拍时间、文字层、AI提示词和验收项以[分镜数据](03-分镜数据.json)为准，修改后运行 `python3 tools/storyboard.py check` 校验。

**本版调整**

| 调整 | 原因 |
|---|---|
| 每镜拆成按秒计时的“拍”，逐拍标明由代码、AI静帧或AI视频完成 | 让代码可以直接按数据渲染，AI生成只承担它擅长的部分 |
| 所有文字、数字、界面、标注和图表改由代码叠加，AI画面内不出现可读文字 | 视频生成模型难以写对中文和界面，文字错误会直接废片 |
| 贯穿对象具体化为“边界样本 #017” | 同一个对象要能承担标注、规则讨论、三维、质检与复用，必须先定下长什么样 |
| 人物镜头去主角化，AI人物以侧面、肩后、手部为主 | AI难以让同一人物跨镜保持一致；连续性改由样本、青色线和调色承担 |
| 需要与画面对齐的标注只叠在静帧或锁定机位上 | 代码知道静帧上每个像素的位置，标注可精确对齐，不必追踪运动镜头 |
| 屏幕文字按阅读速度校时，S06、S09、S10、S14 精简了文字 | 原稿部分镜头在2秒内放了30字以上，观众读不完 |
| 旁白改两句：S12、S13 | S12 与资料中“项目组内跟随生产骨干”对齐；S13 原句不通顺 |

**方案依据**

来源为用户提供的[校招材料](../references/校招原始资料.pdf)。已检查原稿11页，岗位与人数依据第5—9页，培养和评价依据第10页，地点与投递依据第11页。本方案按该材料设计，未将其主张作外部事实核验。

招聘计划合计58人：本科数据标注工程师20人、高端标注／3D建模工程师30人；硕士算法研发工程师5人；博士人工智能研究员3人。58人是招聘计划，不能用来表示现有员工规模。50个本科岗位以数据生产、质检和三维加工为主要工作，因此让这些工作获得足够、准确的画面表现。

材料明确了分层带教：本科在项目组内跟随生产骨干上手，硕博由技术负责人带项目；优秀本科员工可向高端加工、质检管理、标准设计等方向发展。片中用具体带教与交付物表达这些内容，不作保证晋升或薪酬的延伸。

**核心创意**

主题：**让AI看懂真实世界。**

副题：**2027届，来做那个定标准的人。**

观众应得到三个答案：来这里做什么；如何开始、和谁协作；怎样找到适合自己的岗位并投递。公司名称在前15秒内出现，四类岗位各有对应工作画面。

**贯穿对象：边界样本 #017。** 煤化工装置区一段水平工艺管道的法兰连接处，左侧立管上有压力表，右后方有红色阀门手轮。标注目标是法兰下沿的锈蚀与渗漏水痕。它有两处“说不清”的地方：一缕蒸汽挡住了锈迹边缘，压力表玻璃的强反光容易被误标。这个样本在片中依次被发现、调整边界、出现两种判断、写入规范 v1.3、进入三维、让质检脚本据此找出同类样本、回到现场、在带教中被讲解、归档，最后被下一位同事打开复用。

**贯穿图形：青色标注线。** 4像素青色线（#2DD4BF），可以描出边界、变成三维框、连接流程节点，最后画出片尾分隔线。它是全片唯一允许跨镜头延续的图形元素，每个段落至少出现一次。

**制作路线**

| 路线 | 内容 | 本片用途 | 成片时长 |
|---|---|---|---:|
| G 代码生成 | HTML / Canvas / three.js 逐帧渲染 | 文字、标注界面、规范页、点云、终端、白板流程、岗位卡、片尾、转场 | 约94秒（78%） |
| I AI静帧＋代码运动 | 先生成高分辨率静帧，代码做推拉、光效和叠加 | 边界样本主图（S01、S11），其余镜头中作为界面里的图像素材 | 约5秒独立出现 |
| A AI视频底板 | 无文字、无可读屏幕的人物与环境，单段≤5秒 | 眼睛特写、办公室后拉、讨论、带教、手部、侧脸 | 约21秒（8段必需，1段可选） |
| R 实拍替换 | 公司可公开的照片、视频、点云文件 | 可逐个替换 I / A 资产，时间、版式和文字层不变 | 按到位情况 |

制作原则：

1. 文字只由代码生成。AI画面中的屏幕背向镜头或虚焦，白板与纸面不可读，需要看清的内容切到代码画面。
2. AI片段只写一个动作、一种运镜，先出静帧定稿再图生视频，每个资产至少出3个候选，按验收项挑选。
3. 演示界面里的样本编号、版本号和批次号都是示意，不出现客户名称和性能数字。
4. 片头与片尾标注“部分画面由AI生成，仅作工作场景示意”；公司实拍到位后可去掉对应说明。

**旁白与声音处理**

旁白使用清晰、沉稳、带好奇心的年轻声音，正常语速，遇到“数据、标准、真实应用”留短暂停顿，避免大会播报式重音。全片旁白语速控制在每秒3.2—4.4个音节；数据文件中 `vo.tts` 给出朗读写法，“2027届”读作“二零二七届”，“AI”读作字母。

开场5秒只有装置区低频环境声、手电开关声和一次定格轻响，S02起进入简洁电子节奏（建议100 BPM，每拍正好15帧）。标注、复核、键盘等声音只在少数关键动作上出现，提示点已写入各镜 `audio`。63秒带教段音乐降低约4 dB；81秒岗位段节奏稳定；116.5秒音乐收束，最后约3秒只留轻微底噪。这是新片声音设计，不是对参考视频原声的描述。

本版旁白为创作稿，不使用虚构员工证言。配音后用实测时间替换各镜 `vo.t`，镜头长度原则上不变；如需微调，每镜调整不超过0.5秒，总时长维持120秒，片尾完整停留7秒。
