**时长选择**

客户允许2—3分钟。本版定为150秒，理由如下：

- 压在120秒时，S04 试点、交付物、博士岗位卡和片尾的屏幕文字都超过每秒10字，读不完；有7个镜头被压到5秒。150秒让这些镜头恢复到6—9秒，每镜屏幕文字都控制在每秒10字以内。
- 客户文案里有三块对候选人很重要、120秒放不下的内容，本版各给一镜：行业场景与FDE的必要性（S05）、成长通道（S17）、招聘流程与工作地点（S22）。
- 两分半能讲完全部必要信息，再往3分钟加只会增加中途流失的风险；片尾7秒落版不受影响。传播用的30秒精简版另行规划。

**核心创意**

片名：**让AI看懂真实世界。**

片尾标题：**2027届，来做那个定义能源AI模型应用标准的人。**

客户文案写道：煤矿安全培训、设备故障预警、隐患智能识别等工业场景“没有现成AI模型模板，需要完成FDE行业适配，实现模型真正可用”。本片就讲这件事：通用模型第一次看工业现场会看错，智数科技的工作是让它看对。观众应得到五个答案：来这里做什么；为什么是这里；如何开始、和谁协作；以后能往哪里走；怎样找到适合自己的岗位并投递。公司名称在前15秒内出现，国家试点紧随其后，四类岗位各有对应工作画面。

S05 在屏幕上提出“需要完成FDE行业适配，实现模型真正可用”，S13 用旁白“完成FDE行业适配，让模型在现场真正可用”回答，前后呼应。

**贯穿对象：边界案例 017。** 煤化工装置区一段水平工艺管道的法兰连接处，左侧立管上有压力表，右后方有红色阀门手轮，法兰下沿有锈蚀与渗漏水痕。通用模型在这里犯了两个错：把压力表玻璃的反光误判为渗漏，又漏掉了被一缕蒸汽遮住的锈蚀边缘。这个案例在片中依次被发现、对照现场修正、出现两种判断、写入场景应用规范 1.3 版、进入三维场景、帮助校验脚本找出同类漏检样本、经过对照实验、由适配后模型通过现场验证、在带教中被讲解、归档，最后被下一位同事打开复用。

**贯穿图形：青色连接线。** 4像素青色线（#2DD4BF），可以描出真实边界、变成三维框、连接流程节点和成长通道，最后画出片尾分隔线。它是全片唯一允许跨镜头延续的图形元素，每个段落至少出现一次。琥珀色只表示“存疑、待处理”，包括通用模型的误判框。

制作原则：

1. 文字只由代码生成。AI画面中的屏幕背向镜头或虚焦，白板与纸面不可读，需要看清的内容切到代码画面。
2. AI片段只写一个动作、一种运镜，先出静帧定稿再图生视频，每个资产至少出3个候选，按验收项挑选。
3. 适配前后的对比只用单个示意案例；演示界面中的编号与版本号都是示意，不出现客户名称和性能数字。
4. 试点信息用抽象点阵与环形图表达，不使用地图轮廓。
5. 片头与片尾注明“部分画面由AI生成，仅作工作场景示意”；公司实拍到位后可去掉对应说明。

**旁白与声音处理**

旁白使用清晰、沉稳、带好奇心的年轻声音，正常语速，遇到“现场、模型、标准”留短暂停顿，避免大会播报式重音。全片旁白语速控制在每秒3.6—4.4个音节；数据文件中 `vo.tts` 给出朗读写法，“2027届”读作“二零二七届”，“AI”和“FDE”逐个字母读出。

开场5秒只有装置区低频环境声、手电开关声和误判框出现时的一声低沉提示，S02起进入简洁电子节奏（建议每分钟100拍，每拍正好15帧）；S04、S05 试点与行业场景段节奏略提。79秒带教段音乐降低约4分贝；97秒成长通道段旋律逐步抬升；104秒岗位与投递段节奏稳定；138秒回扣段情绪抬升；146.5秒音乐收束，最后约3秒只留轻微底噪。键盘、点击、确认等声音只在少数关键动作上出现，提示点已写入各镜 `audio`。

本版旁白为创作稿，不使用虚构员工证言。配音后用实测时间替换各镜 `vo.t`，镜头长度原则上不变；如需微调，每镜调整不超过0.5秒，片尾完整停留7秒。

**事实使用边界与待补信息**

- 试点信息依据客户提供的介绍：入选主体是平顶山市，中国平煤神马集团是试点申报的中坚力量，智数科技是试点任务的核心运营载体（见客户文案）。片中写清三者各自的角色，不把城市入选写成公司获批。
