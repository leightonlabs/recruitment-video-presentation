# 智数科技 2027 届校园招聘视频

本仓库整理河南平煤神马智数科技有限公司校招视频的创意方案、制作数据与旁白，保存客户最新提供的校招文案、旧版招聘 PDF 及其 11 页图片，以及三部参考片的分析。

当前为 **v4 版**，已按客户更新文案与试点介绍调整为“能源化工行业 AI 模型应用”定位。片名 **《让 AI 看懂真实世界》**，片尾标题“2027届，来做那个定义能源AI模型应用标准的人”。主版时长 **150 秒（2 分 30 秒）、24 个分镜、16:9、25 fps**，9:16 版由代码按竖版版式重排。已可按分镜数据生成 150 秒粗剪，最终视频尚未制作。

## 核心创意

通用模型第一次看工业现场会看错，需要完成 FDE 行业适配才能真正可用：它把压力表的反光当成渗漏，又漏掉被蒸汽遮住的锈蚀边缘。全片用这一个“边界案例 017”贯穿：对照现场修正、对齐场景规则、搭建三维场景、校验与适配实验，直到适配后的模型通过现场验证，案例写进可复用的场景应用规范，被下一位同事打开使用。一条青色连接线串起这些环节，让候选人看清工作任务、协作方式和岗位选择。

| 片段 | 时间 | 任务 |
|---|---|---|
| 提问、公司与试点 | 00:00–00:31 | 通用模型在现场看错；前 15 秒交代企业归属；平顶山“国字号”数据标注试点与智数科技的角色；能源场景没有现成模板，需要 FDE 行业适配 |
| 工作内容 | 00:31–01:19 | 数据与三维场景配套、规则对齐、校验与实验，完成 FDE 行业适配 |
| 带教与成长 | 01:19–01:44 | 用具体动作和交付物表达培养方式、完整 FDE 技术栈与成长通道 |
| 招聘岗位与投递 | 01:44–02:18 | 2027 届计划招聘 58 名“模型先锋”：模型配套工程师 20、高端场景建模工程师 30、算法研发工程师 5、人工智能研究员 3；招聘流程与工作地点 |
| 回扣与落版 | 02:18–02:30 | 回到规范复用，完整落版保持 7 秒 |

## 制作方式

每个镜头按秒拆成“拍”，逐拍标明制作路线：

| 路线 | 内容 | 成片占比 |
|---|---|---:|
| 代码生成 | 文字、试点信息图、行业场景卡、场景工作台、规范页、点云、终端、白板、成长通道、岗位卡、招聘流程、片尾、转场 | 约 82% |
| AI 静帧＋代码运动 | 边界案例主图，代码做推拉、光效与精确框线 | 约 4% |
| AI 视频底板 | 无文字的人物与环境画面，9 段必需、1 段可选，单段不超过 5 秒 | 约 15% |
| 实拍替换 | 公司素材到位后逐个替换 AI 资产，时间与版式不变 | — |

所有文字由代码叠加，AI 画面内不出现可读文字；与画面对齐的框线只叠在静帧或锁定机位上。按客户要求，旁白与屏幕文字统一用词、以中文为主，校验工具会自动检查。

修改分镜后运行校验，并按需导出字幕或重新生成提示词表（仅需 Python 3 标准库）：

```bash
python3 tools/storyboard.py check     # 校验时间、阅读速度、配音语速、用词与资产引用
python3 tools/storyboard.py summary   # 按镜头列出路线与语速
python3 tools/storyboard.py srt       # 导出 build/subtitles.srt
python3 tools/storyboard.py lrc       # 导出 build/subtitles.lrc（LRC 格式）
python3 tools/storyboard.py prompts   # 重新生成 docs/07-AI生成提示词.md
```

生成视频（AI 画面、主图与旁白均为占位）：

```bash
node render/build.mjs --clean         # 精修版：输出 build/精修版-150秒-1080p.mp4
node render/build.mjs                 # 粗剪：带审阅信息条，另出 720p 预览版
```

在自己电脑上运行所需的软件与步骤见 [render/README.md](render/README.md)；也可以在仓库的 Actions 页面运行“渲染视频并发布”，由 GitHub 渲染后把成片发布到 Releases。

## 资料边界

- 公司定位、岗位计划与培养机制依据客户提供的更新版校招文案，未作外部事实核验。
- 58 人是招聘计划，其中本科 50 人、硕士 5 人、博士 3 人，不代表现有员工规模。
- 分镜是拟制设计，示意界面中的编号、版本与代码不能视为现有项目、系统或设备已经落地的证明。
- 片中 AI 生成画面仅作工作场景示意，片头片尾附提示；公司实拍到位后可替换。
- 试点信息按客户提供的介绍表述：入选的是平顶山市，集团是试点申报中坚力量，智数科技是试点任务核心运营载体；试点名称使用正式全称。
