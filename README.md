# 智数科技 2027 届校园招聘视频

本仓库整理河南平煤神马智数科技有限公司校招视频的创意方案、制作数据、旁白及已生成的 11 页校招资料图片，并保留招聘原始 PDF 及三部参考片的分析。

当前为 **v2 制作版**，主题为 **《让 AI 看懂真实世界》**，副题为“2027 届，来做那个定标准的人”。主版时长 **120 秒、20 个分镜、16:9、25 fps**，9:16 版由代码按竖版版式重排。当前尚未制作最终视频。

## 核心创意

用同一份能源设备“边界样本 #017”贯穿全片：法兰下沿的锈蚀渗漏被蒸汽遮挡、旁边压力表反光。它从现场图像进入标注工具，经过规则讨论、规范迭代、三维加工与算法质检，最后成为下一位同事能够复用的案例。一条青色标注线连接这些环节，让候选人看清工作任务、协作方式和岗位选择。

| 片段 | 时间 | 任务 |
|---|---|---|
| 提问与公司登场 | 00:00–00:15 | 从具体样本提出问题，前 15 秒交代企业归属 |
| 工作内容 | 00:15–01:03 | 展示数据加工、规则对齐、三维、质检与研究 |
| 带教与积累 | 01:03–01:21 | 用具体动作和交付物表达培养方式 |
| 招聘岗位 | 01:21–01:48 | 呈现 2027 届计划招聘 58 人及四类岗位 |
| 回扣与投递入口 | 01:48–02:00 | 回到规范复用，完整落版保持 7 秒 |

## 制作方式

每个镜头按秒拆成“拍”，逐拍标明制作路线：

| 路线 | 内容 | 成片占比 |
|---|---|---:|
| 代码生成 | 文字、标注界面、规范页、点云、终端、白板、岗位卡、片尾、转场 | 约 78% |
| AI 静帧＋代码运动 | 边界样本主图，代码做推拉、光效与精确标注 | 约 5% |
| AI 视频底板 | 无文字的人物与环境画面，8 段必需、1 段可选，单段不超过 5 秒 | 约 17% |
| 实拍替换 | 公司素材到位后逐个替换 AI 资产，时间与版式不变 | — |

所有文字由代码叠加，AI 画面内不出现可读文字；与画面对齐的标注只叠在静帧或锁定机位上。

修改分镜后运行校验，并按需导出字幕或重新生成提示词表（仅需 Python 3 标准库）：

```bash
python3 tools/storyboard.py check     # 校验时间、阅读速度、配音语速与资产引用
python3 tools/storyboard.py summary   # 按镜头列出路线与语速
python3 tools/storyboard.py srt       # 导出 build/subtitles.srt
python3 tools/storyboard.py prompts   # 重新生成 docs/07-AI生成提示词.md
```

## 资料边界

- 业务方向“AI 应用开发”由用户说明；岗位计划与培养机制依据用户提供的招聘 PDF，未作外部事实核验。
- 58 人是招聘计划，其中本科 50 人、硕士 5 人、博士 3 人，不代表现有员工规模。
- 分镜是拟制设计，示意界面中的编号、版本与代码不能视为现有项目、系统或设备已经落地的证明。
- 片中 AI 生成画面仅作工作场景示意，片头片尾附提示；公司实拍到位后可替换。
- 原材料中的发展目标不按已建成能力表述；“全国唯一”“国字号试点”等主张暂未进入旁白。
- 正式投递二维码或邮箱、薪酬福利、正式 Logo 和可公开项目素材仍待补齐，详见制作准备文档。

本仓库不包括三个参考 MP4 原片、全量抽帧、音频、失败的语音识别结果或依赖缓存。所有文档使用仓库内相对链接，不保留用户微信附件的本地目录。
