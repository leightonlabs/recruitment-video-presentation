# 智数科技 2027 届校园招聘视频

本仓库整理河南平煤神马智数科技有限公司校招视频的创意方案、制作数据与旁白，保存客户最新提供的校招文案、旧版招聘 PDF 及其 11 页图片，以及三部参考片的分析。

当前为 **v3 版**，已按客户更新文案调整为“能源化工行业 AI 模型应用”定位。片名 **《让 AI 看懂真实世界》**，片尾标题“2027届，来做那个定义能源AI模型应用标准的人”。主版时长 **120 秒、20 个分镜、16:9、25 fps**，9:16 版由代码按竖版版式重排。当前尚未制作最终视频。

## 核心创意

通用模型第一次看工业现场会看错：它把压力表的反光当成渗漏，又漏掉被蒸汽遮住的锈蚀边缘。全片用这一个“边界案例 017”贯穿：对照现场修正、对齐场景规则、搭建三维场景、校验与适配实验，直到适配后的模型通过现场验证，案例写进可复用的场景应用规范，被下一位同事打开使用。一条青色连接线串起这些环节，让候选人看清工作任务、协作方式和岗位选择。

| 片段 | 时间 | 任务 |
|---|---|---|
| 提问与公司登场 | 00:00–00:15 | 通用模型在现场看错，前 15 秒交代企业归属 |
| 工作内容 | 00:15–01:03 | 数据与三维场景配套、规则对齐、校验与实验，模型通过现场验证 |
| 带教与积累 | 01:03–01:21 | 用具体动作和交付物表达培养方式 |
| 招聘岗位 | 01:21–01:48 | 2027 届计划招聘 58 名“模型先锋”：模型配套工程师 20、高端场景建模工程师 30、算法研发工程师 5、人工智能研究员 3 |
| 回扣与投递入口 | 01:48–02:00 | 回到规范复用，完整落版保持 7 秒 |

## 制作方式

每个镜头按秒拆成“拍”，逐拍标明制作路线：

| 路线 | 内容 | 成片占比 |
|---|---|---:|
| 代码生成 | 文字、场景工作台、规范页、点云、终端、白板、岗位卡、片尾、转场 | 约 78% |
| AI 静帧＋代码运动 | 边界案例主图，代码做推拉、光效与精确框线 | 约 5% |
| AI 视频底板 | 无文字的人物与环境画面，8 段必需、1 段可选，单段不超过 5 秒 | 约 17% |
| 实拍替换 | 公司素材到位后逐个替换 AI 资产，时间与版式不变 | — |

所有文字由代码叠加，AI 画面内不出现可读文字；与画面对齐的框线只叠在静帧或锁定机位上。按客户要求，旁白与屏幕文字统一用词、以中文为主，校验工具会自动检查。

修改分镜后运行校验，并按需导出字幕或重新生成提示词表（仅需 Python 3 标准库）：

```bash
python3 tools/storyboard.py check     # 校验时间、阅读速度、配音语速、用词与资产引用
python3 tools/storyboard.py summary   # 按镜头列出路线与语速
python3 tools/storyboard.py srt       # 导出 build/subtitles.srt
python3 tools/storyboard.py prompts   # 重新生成 docs/07-AI生成提示词.md
```
