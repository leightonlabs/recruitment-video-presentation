# 粗剪渲染

按 [分镜数据](../docs/03-分镜数据.json) 逐帧渲染 150 秒粗剪，用于审节奏、版式与文字。所有画面、文字和时间都从分镜数据读取：改了 JSON 后重新运行即可，不需要改代码。

## 一键生成

```bash
./render/build.sh        # 默认 4 个进程并行
```

依赖：Node.js 22、Playwright 自带的 Chromium、FFmpeg、Python 3 与 numpy。首次运行会安装 three.js，并从 Google Fonts 下载 Noto Sans SC、JetBrains Mono、Long Cang（均为 SIL OFL 1.1）。

输出（`build/` 目录不入库）：

| 文件 | 说明 |
|---|---|
| `build/粗剪-v4-150秒.mp4` | 1920×1080、25 帧/秒，带临时音轨与字幕 |
| `build/粗剪-v4-150秒-720p.mp4` | 1280×720 预览版，便于转发 |
| `build/assets/hero.png`、`hero_anchors.json` | 占位主图及目标多边形、反光框、蒸汽区坐标 |
| `build/roughcut/` | 中间文件：无声画面、配乐、音效、旁白提示音、字幕 |

单独渲染审阅静帧：

```bash
node render/render.mjs stills 2.4,30,61 build/review   # 参数为全片秒数
```

## 粗剪里的占位

| 内容 | 粗剪中的处理 | 正式版替换为 |
|---|---|---|
| AI 视频底板（A 路线） | 带资产编号、画面描述与取用时长的占位卡，背景按运镜方式缓动 | 按 [提示词表](../docs/07-AI生成提示词.md) 生成的视频 |
| 边界案例主图（I 路线） | 由与点云相同的程序模型渲染的占位主图，坐标由几何体投影算出 | 定稿的 AI 主图或实拍；读图标定后写入 `hero_sample.polygon` |
| 同类样本图 | 由占位主图裁切、调色、加蒸汽或雨痕得到 | `IMG_SAMPLES` 或公司样本图 |
| 旁白 | 与每句旁白音节数一致的提示音，标出位置与语速 | 正式配音 |
| 配乐与音效 | 按 `music` 与 `audio` 字段合成的临时声音 | 授权配乐与音效 |
| 投递二维码 | 虚线占位框 | 公司提供的二维码 |

右上角的审阅信息条显示粗剪版本、镜号、时间码和当前画面的制作路线，便于按时间点提修改意见；正式版去掉。

## 文件

| 文件 | 作用 |
|---|---|
| `film.html`、`film.js` | 时间轴、文字层（读取各镜 `text` 字段排版）与审阅信息条 |
| `scenes2d.js` | 二维场景：AI 占位卡、主图动画、场景工作台、信息图、岗位卡、片尾 |
| `scenes3d.js` | 三维场景：主图粒子化、点云、点云场景生长、三视图 |
| `draw.js` | 颜色、缓动、描线、文字等通用绘图工具 |
| `geometry.js` | 占位主图与点云共用的几何参数 |
| `hero.html` | 占位主图渲染页 |
| `render.mjs` | 无头 Chromium 逐帧截图与并行编码 |
| `audio.py`、`subs.py` | 临时音轨合成与字幕转换 |
| `build.sh` | 一键生成 |
